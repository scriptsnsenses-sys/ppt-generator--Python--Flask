📄 PPT Generator (Python + Flask)

A lightweight PPT Generator Web App built using Python, Flask, and python-pptx.
This project allows users to enter content through a web form and automatically generates a PowerPoint (.pptx) file for download.

🚀 Features

📝 Generate PowerPoint presentations dynamically

🌐 Simple and clean Flask-based web interface

📥 Instant PPT download

🎨 Custom content fields (title, subtitle, description, points, etc.)

⚡ Fast and lightweight

🧩 Easy to extend (add images, multiple slides, custom themes)

🛠️ Tech Stack
Backend

Python 3.x

Flask

python-pptx (for generating PowerPoint files)

Frontend

HTML

CSS

JavaScript

Bootstrap (optional)
